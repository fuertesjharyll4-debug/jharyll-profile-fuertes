# Jharyll's Programmer Profile

A responsive personal programmer profile built with Next.js and CSS.

## Sections
- Home
- About
- Education
- Projects
- Contact

## Run locally
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000 in your browser.

## Before publishing
In `app/page.tsx`, replace `your-email@gmail.com` with your actual contact email address.

## Deploy
Import this repository into Vercel and use the default Next.js settings.
